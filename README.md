# N.O.R.D. 3.0

Telegram-бот игрового сообщества для симулятора пилотов (мира «Нордхайм»).

## Механики

- **Валюты**: Нордмарки (основная, без лимита), Очки действия (AP, лимит 150, +100/день)
- **Звания**: система рангов по накопленным войскам
- **Профиль**: фото, статус, карточка пилота
- **Банк**: баланс, переводы по @username, история транзакций
- **Город Аркхольм**: столица Нордхайма (здания, производство, подземелье — в разработке)
- **Магазин и инвентарь**: предметы 5 уровней редкости (Обычный / Качественный / Редкий / Шедевр / Легендарный)
- **Отчёты**: приём скриншотов, авто-проверка до порога, ручная модерация выше
- **Состояние**: шкала 0–100
- **Взаимодействия**: помощь, похвала, поддержка, дуэль

## Админ-панель (по ролям)

- **Хранитель (super_admin)** — полный доступ
- **Министр торговли (shop_admin)** — управление магазином
- **Министр финансов (finance_admin)** — начисление/списание НМ и AP
- **МВД (moderator)** — проверка отчётов

## Технологии

- Python 3.12
- aiogram 3.x
- aiosqlite (SQLite)
- python-dotenv

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Конфигурация — в файле `.env` (BOT_TOKEN, ADMIN_IDS, DATABASE_PATH).
